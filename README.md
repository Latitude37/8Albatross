# Albatross development microsite

Fresh GitHub Pages build for 8 and 8A Albatross Avenue, Mount Eliza.

## Upload to GitHub

Upload the CONTENTS of this folder to the root of the repository.

The repository should show:
- `Discover/`
- `index.html`
- `README.md`

Then enable GitHub Pages from `main` and `/ (root)`.

The root redirects to `/Discover/`.
